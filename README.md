# Facebook Messenger AI бот — тусгай зөвшөөрлийн хүсэлт авах

Пэйж рүү бичсэн хүнтэй Claude 24/7 харилцаж, хоёрхон зүйл асууна:
1. Ямар чиглэлийн эмнэлгийн тусгай зөвшөөрөл авах сонирхолтой байгааг.
2. Утасны дугаарыг нь. Асуухдаа дугаарыг зөвхөн тантай холбогдоход ашиглана гэж зорилгыг нь хэлнэ.

Хэрэглэгч дугаараа бичмэгц ажилтнуудын Telegram групп руу **«📞 Шинэ хүсэлт»** мэдэгдэл очно. Мэдэгдэлд чиглэл, утас, ирсэн цаг, хүсэлтийн дугаар байна. Ажилтан залгана.

```
Хэрэглэгч → Messenger → Meta webhook → Vercel /api/webhook
   ├─ гарын үсэг шалгана (META_APP_SECRET), 200-г шууд буцаана
   ├─ давхар ирсэн мессежийг алгасна (Redis)
   ├─ утасны дугаар таних (код, AI биш) → хүсэлтийг Redis-д хадгална (outbox)
   ├─ Claude → хариулт → аюулгүй байдлын шүүлтүүр → Messenger
   └─ хүсэлт → Telegram (3 оролдлого) → хүрсэн бол Redis-ээс устгана
                                       → хүрээгүй бол outbox-д үлдэж, дахин илгээгдэнэ
Vercel Cron (өдөр бүр 09:00 УБ) → /api/health → token, webhook, Telegram, Redis шалгаж, outbox-ийг дахин илгээнэ
```

## Ботын дүрэм
- Зөвхөн чиглэл болон утасны дугаар асууна. Нэр, регистр, хаяг, имэйл асуухгүй. Дугаараа өгөхгүй гэвэл шахахгүй.
- **Үнэ, хаяг, байгууллагын утас, холбоос, хууль журмын дугаар, хугацаа хэлэхгүй.** Prompt-оор хориглохоос гадна код хариулт бүрийг илгээхээсээ өмнө шалгадаг. Ийм зүйл илэрвэл AI-ын хариултын оронд «мэргэжилтэн утсаар тайлбарлана» гэсэн тогтмол хариулт очно.
- **Утасны дугаарыг AI биш, код таньдаг.** 5–9-өөр эхэлсэн 8 оронтой тоог дугаар гэж үзнэ. Урдаа +976 байж, 2 эсвэл 4 оронгоор зай, зураас, цэгээр тусгаарлагдаж болно. Мөнгөн дүн (`50 000 000₮`) болон регистрийн дугаарыг дугаар гэж андуурахгүй.
- Латин үсгээр бичсэн монгол хэл (`sain baina uu`), товчилсон (`сн уу`), үг үсгийн алдаатай бичвэрийг ойлгоно. Хариулахдаа кирилл үсгээр, зөв бичгийн дүрмийн дагуу бичнэ.
- «Миний мэдээллийг устгана уу» гэвэл ажилтанд мэдэгдэнэ.
- «Хүн үү?» гэж асуувал AI гэдгээ хэлнэ. Яаралтай тохиолдолд 103, 102 руу залгахыг зөвлөнө.

## Хүсэлт алдагдахгүй, давхардахгүй
- Хүсэлтийг Claude-ыг дуудахаас **өмнө** Redis-д хадгална. Функц тасарсан ч дараа нь outbox-оос илгээгдэнэ.
- Telegram руу шууд 3 удаа оролдоно. Бүтэлгүйтвэл хүсэлт outbox-д үлдэж, дараагийн webhook бүрээр болон өдрийн cron-оор дахин илгээгдэнэ.
- Нэг хэрэглэгчийн нэг дугаарыг 30 хоногийн дотор **ганц удаа** мэдэгдэнэ. Хоёр сервер нэгэн зэрэг илгээхээс түгжээ (lock) хамгаална.
- Telegram хүлээж авмагц утасны дугаар Redis-ээс устгагдана. Хүрээгүй хүсэлт хамгийн ихдээ 30 хоног хадгалагдана.
- Redis ажиллахгүй байсан ч хүсэлт Telegram руу шууд илгээгдэнэ.
- Log-д утасны дугаар болон хэрэглэгчийн мессеж бичигдэхгүй.

## Telegram-д ирэх мэдэгдлүүд
| Мэдэгдэл | Хэзээ ирэх вэ |
|---|---|
| 📞 Шинэ хүсэлт | Хэрэглэгч утасны дугаараа бичсэн |
| 🙋 Ажилтан хариулах шаардлагатай | Гомдол, яаралтай хүсэлт, устгах хүсэлт ирсэн (дугааргүй) |
| ⚠️ AI хариулт гаргаж чадсангүй | Claude түр ажиллахгүй байсан |
| 📎 Зураг/файл | Хэрэглэгч зураг эсвэл файл илгээсэн |
| 🚨 Ботын шалгалт | Token, webhook, Redis-д асуудал гарсан, эсвэл хүсэлт хүлээгдэж байна |

## Хаягууд
| Хаяг | Зориулалт |
|---|---|
| `/api/webhook` | Meta webhook (Callback URL) |
| `/privacy` | Нууцлалын бодлого. Meta аппын Privacy Policy URL. `/privacy#delete` нь мэдээлэл устгах заавар. |
| `/api/health` | Шалгалт. `Authorization: Bearer <CRON_SECRET>` шаардана. |
| `/api/setup/status` | Дутуу environment variable-уудын нэр (утгыг биш), Redis холбогдсон эсэх, ажиллаж буй commit. `CRON_SECRET` шаардана. |
| `/api/setup/telegram` | Ботын харсан Telegram чатуудыг жагсаана (`TELEGRAM_CHAT_ID` олоход). `CRON_SECRET` шаардана. |
| `/api/admin/selftest` | Redis болон Telegram-ыг production дээр шалгана. `CRON_SECRET` болон `ADMIN_TOOLS=true` шаардана. |
| `/api/admin/simulate` | Монгол хэлний тест: бодит prompt болон загвараар хариулт гаргана, юу ч илгээхгүй. `CRON_SECRET` болон `ADMIN_TOOLS=true` шаардана. |

Тест дууссаны дараа `ADMIN_TOOLS`-ийг `false` болгоно.

| Upstash Redis (Vercel Marketplace, free tier) | $0 |
| Vercel | Hobby $0. **Hobby нь арилжааны бус хэрэглээнд зориулагдсан.** Бизнесийн ботод Pro ($20) тохиромжтой бөгөөд outbox-ийг 5 минут тутам шалгах cron-ийг идэвхжүүлдэг. |

Үнийг Anthropic, Vercel-ийн үнийн хуудаснаас шалгаарай. `CLAUDE_MODEL=claude-sonnet-5-5` болговол Монгол хэлний чанар сайжирна (нэг хариулт ≈ $0.009).

## Ботыг унтраах
Vercel env-д `BOT_ENABLED=false` болгоод Redeploy хийнэ. Бот хариулахгүй, та гараар хариулна.

## Мэдэгдэж буй хязгаарлалт
- **Олон нийтэд хариулах эрх.** Аппад эрхгүй хүнд бот хариулахгүй байвал Meta аппыг Live болгож, шаардлагатай бол `pages_messaging`-ийн Advanced Access-ийг App Review-гээр авна.
- **Hobby дээр outbox өдөрт нэг удаа шалгагдана.** Үүнээс гадна шинэ мессеж бүрээр шалгагдана. Pro дээр `vercel.json`-ийн cron-ийг `*/5 * * * *` болгоно.
- **Дугаараа эхэлж өгвөл чиглэл «тодорхойгүй» гарна.** Ажилтан утсаар тодруулна.
- **Ажилтан орж ирэхэд бот өөрөө зогсохгүй.**
