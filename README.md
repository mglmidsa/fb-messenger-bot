# Facebook Messenger AI бот (1 пэйж)

Пэйж рүү ирсэн Messenger мессежид Claude 24/7 автоматаар хариулна. Хариулж чадахгүй асуулт, гомдол болон хүнтэй ярих хүсэлтийг ажилтанд шилжүүлж, танд Telegram-аар мэдэгдэнэ.

```
Хэрэглэгч → Messenger → Meta webhook → Vercel (/api/webhook)
                                          ├─ гарын үсэг шалгана (META_APP_SECRET)
                                          ├─ 200-г шууд буцаана
                                          └─ дараа нь: яриан түүх → Claude → хариулт илгээнэ
                                                                    └─ шаардлагатай бол → Telegram мэдэгдэл
Vercel Cron (өдөр бүр 09:00) → /api/health → token, webhook шалгана → асуудал байвал Telegram
```

## Ботын дүрэм
- Зөвхөн `lib/knowledge.ts` доторх мэдээллээр хариулна. Үнэ, хөнгөлөлт, амлалт зохиохгүй.
- Мэдэхгүй асуултад «ажилтанд дамжууллаа» гэж хариулаад танд мэдэгдэнэ.
- Зураг эсвэл файл ирвэл хүлээн авснаа мэдэгдээд танд дамжуулна. Зургийн агуулгыг уншихгүй.
- AI алдаа гарвал эелдэг түр хариулт илгээж, танд мэдэгдэнэ. Хэрэглэгч хариугүй үлдэхгүй.
- Картын дугаар, нууц үг асуухгүй. «Хүн үү?» гэж асуувал AI гэдгээ хэлнэ.
- Мэдлэгийн сан бөглөгдөөгүй үед AI ажиллахгүй, бүх мессежийг танд шилжүүлнэ.

## Тохируулах алхмууд

### 1. Мэдлэгийн сан бөглөх
`lib/knowledge.ts` файлын `[...]` хэсгүүдийг бөглөнө: нэр, үйлчилгээ, цаг, хаяг, үнэ, захиалга, түгээмэл асуултууд. Ботын хариултын чанар бүхэлдээ энэ файлаас хамаарна.

### 2. Meta апп үүсгэх
1. developers.facebook.com → **My Apps → Create App**
2. Use case: **Engage with customers on Messenger from Meta**, эсвэл Messenger-тэй холбоотой use case
3. Business portfolio-оо холбоно
4. **App settings → Basic** хэсгээс **App ID** болон **App Secret**-ийг хуулж авна. Privacy Policy URL шаардвал энгийн нэг хуудас тавина.

### 3. Claude API түлхүүр
platform.claude.com → **API Keys → Create key**. **Billing → Spend limit** дээр сарын дээд хязгаар тавиарай. Эхлээд $10 хангалттай.

### 4. Vercel-д байршуулах
1. Энэ хавтсыг GitHub-д шинэ private repo болгон оруулна
2. vercel.com → **Add New → Project** → тэр repo-г сонгоно
3. **Environment Variables**-д `.env.example` доторх утгуудыг оруулна. `PAGE_ID` болон `PAGE_ACCESS_TOKEN`-ыг 6-р алхмын дараа нэмнэ.
   - `WEBHOOK_VERIFY_TOKEN`, `CRON_SECRET`: санамсаргүй урт текст байна. Жишээ нь `openssl rand -hex 24`.
4. Deploy хийнэ. Хаяг нь `https://<нэр>.vercel.app` хэлбэртэй гарна.

### 5. Webhook холбох
Meta апп → **Messenger → Messenger API Settings → Configure webhooks**
- Callback URL: `https://<нэр>.vercel.app/api/webhook`
- Verify token: `WEBHOOK_VERIFY_TOKEN`-той яг ижил утга
- Subscription fields: **messages**, **messaging_postbacks**

### 6. Page token авах
1. developers.facebook.com/tools/explorer → өөрийн аппаа сонгоно
2. **Get User Access Token** дарж дараах эрхүүдийг сонгоно: `pages_show_list`, `pages_messaging`, `pages_manage_metadata`, `pages_read_engagement`, `business_management`
3. Гарсан token-ыг хуулж, өөрийн компьютер дээр ажиллуулна:
   ```bash
   META_APP_ID=... META_APP_SECRET=... USER_TOKEN=... node scripts/get-page-token.mjs <PAGE_ID>
   ```
   Скрипт урт хугацааны token гаргаж, пэйжийг webhook-д бүртгээд `PAGE_ID` болон `PAGE_ACCESS_TOKEN`-ыг хэвлэнэ.
4. Тэдгээрийг Vercel env-д нэмээд **Redeploy** хийнэ.

### 7. Telegram мэдэгдэл (зөвлөж байна)
- Telegram дээр @BotFather → `/newbot` → token-ыг `TELEGRAM_BOT_TOKEN`-д хийнэ
- Шинэ ботдоо нэг мессеж бичнэ. Дараа нь @userinfobot-оос өөрийн ID-г авч `TELEGRAM_CHAT_ID`-д хийнэ.

### 8. Турших
1. **Өөрийн бүртгэлээс** пэйж рүү бичнэ. Бот хариулах ёстой.
2. **Аппад ямар ч эрхгүй найзын бүртгэлээс** бичнэ. ⚠️ Энэ бол хамгийн чухал тест (доорх эрсдэлийг үзнэ үү).
3. Мэдлэгийн санд байхгүй асуулт асууна. «Ажилтанд дамжууллаа» гэж хариулж, Telegram мэдэгдэл ирэх ёстой.

## Ботыг унтраах
Vercel env-д `BOT_ENABLED=false` болгоод Redeploy хийнэ. Мессеж ирсээр байх ч бот хариулахгүй, та гараар хариулна.

## Мэдэгдэж буй хязгаарлалт
- **Олон нийтэд хариулах эрх (баталгаажуулах шаардлагатай).** Meta-гийн баримт бичигт өөрийн пэйжийн мессежинд App Review шаардлагагүй гэж бичсэн. Гэхдээ Standard Access нь аппад эрхтэй хүмүүсээр хязгаарлагддаг гэж бас бичсэн. Тиймээс эрхгүй хүнд хариулах эсэхийг 8.2-р тестээр шалгана. Ажиллахгүй бол `pages_messaging`-ийн Advanced Access-ийг App Review-гээр авна. Үүнд хэдэн өдрөөс хэдэн долоо хоног зарцуулагдаж, Business Verification шаардагдаж магадгүй.
- **Ажилтан орж ирэхэд бот өөрөө зогсохгүй.** Ажилтан гараар хариулсны дараа хэрэглэгч дахин бичвэл бот бас хариулна. Үүнийг засахад хадгалах сан (Supabase/KV) хэрэгтэй тул Pro руу шилжсэний дараа нэмнэ.
- **Давхардлын хамгаалалт хагас дутуу.** Meta ижил мессежийг дахин илгээвэл давхар хариулахаас сэргийлэх хамгаалалт зөвхөн нэг серверийн санах ойд ажилладаг. Ховор тохиолдолд давхар хариулт гарч болно.
- **24 цагийн дүрэм.** Хариултыг зөвхөн хэрэглэгч бичсэн даруйд илгээдэг тул энэ дүрэмд үргэлж нийцнэ. Бот хэрэглэгч рүү өөрөө түрүүлж бичихгүй.
